# Odaklanma_Takibi_ve_Raporlama_Uygulamasi
## Kurulum

**Minimum requirements**
```
react-native >= 0.72.0
expo >= 52 (if you use Expo Go)
typescript >= 5.0.0 (if you use TypeScript)
```
**Starter template**
```
npx create-expo-app@latest --template react-navigation/template
```

**React navigation kurulum**
```
npm install @react-navigation/native
```

**Geri sayım bileşeni**
```
react-native-countdown-circle-timer
```

**@react-navigation/native, @react-navigation/bottom-tabs**
```
npx expo install react-native-gesture-handler react-native-reanimated react-native-screens react-native-safe-area-context
```

**Veri ve grafikler**
```
npx expo install expo-sqlite react-native-svg
```
```
npm i react-native-chart-kit @react-native-picker/picker
```

**Tailwindcss**
```
npx expo install tailwindcss@3 postcss autoprefixer --dev
```
```
npx tailwindcss init -p
```

**Uygulamayı çalıştırma**
```
npx expo start
```
